# Contributing

Contributions are very welcome! Here's how to get started:

## Local setup

```sh
git clone https://github.com/KhalfaouiAnis/react-native-anchor-dropdown
cd react-native-anchor-dropdown
npm install
npm run dev   # watches src/ and rebuilds on change
```

## Ways to contribute

- 🐛 **Bug reports** — open an issue with a minimal reproduction
- 💡 **Feature requests** — open an issue describing the use case first
- 🔧 **Pull requests** — for small fixes, just open a PR. For larger changes,
  open an issue first so we can align before you invest time

## PR checklist

- [ ] `npm run build` passes
- [ ] `npm run typecheck` passes
- [ ] README updated if the public API changed
